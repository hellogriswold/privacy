Privacy Policy

Griswold reference boards · Effective 19 October 2026

Griswold reference boards is a personal tool built and used by Griswold, a one-person design studio. It connects to the Pinterest API so the account owner can read their own boards and pins and save them as design references. This page explains what the tool touches and what it does not.

Who uses the tool

One person: the Pinterest account owner. The tool is not offered to the public and has no other users.

What data it reads

  • Board details for the owner's own account: board names, descriptions and pin counts.
  • Pin details on those boards: titles, descriptions, links and image URLs, plus the pin images themselves when the owner chooses to download a board.
  • Basic account information needed to confirm which account is connected.

Pinterest API scopes requested: boards:read, pins:read and user_accounts:read. All read-only.

What it never does

  • It does not create, edit, schedule or delete pins or boards.
  • It does not read other people's private data.
  • It does not sell, rent or share any data with third parties.
  • It does not run ads, analytics or tracking. This page sets no cookies.

Where data is kept

Everything stays on the owner's own computer. The Pinterest access token is stored in a local file on that machine. Downloaded references live in the owner's project folders and are used only as visual reference for design work.

Deleting data and revoking access

The owner can delete downloaded references and the local token file at any time. Access can also be revoked from Pinterest under Settings, Security, Connected apps. Revoking access stops the tool immediately.

Third parties

The only third party involved is Pinterest, which provides the API. Pinterest's own privacy policy governs how Pinterest handles account data.

Changes

If the tool changes in a way that affects this policy, this page will be updated and the effective date above will change.
